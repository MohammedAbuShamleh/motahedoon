# موقع تجمع متحدون من أجل غزة

موقع تعريفي مؤسسي **دائم**. التجمع هو الثابت، والتقرير الدوري دليل واحد داخله لا محوره.
موقع ثابت (static): لا قاعدة بيانات ولا خادم تطبيقات ولا خطوة بناء ولا مكتبات خارجية.

## البنية

```
index.html                 الصفحة الرئيسية — تعريفية دائمة
pillar.html                قالب واحد يخدم كل الصفحات الداخلية عبر ?id=
assets/
  css/style.css            نظام التنسيق كاملاً
  js/data.js               ← كل النصوص والأرقام. هنا وحده يُحدَّث المحتوى
  js/app.js                بناء الصفحات من data.js
  img/logos/               شعار التجمع + شعارات المؤسسات (PNG شفاف)
  img/photos/              الصور الميدانية (أبيض وأسود، مضغوطة)
```

**المسارات:**

| الرابط | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `pillar.html?id=report` | **صفحة الإنجازات** — أحدث تقرير كاملاً |
| `pillar.html?id=q3-2026` · `q2-2026` | إنجازات فترة بعينها من الأرشيف |
| `pillar.html?id=dawah` · `quran` · `relief` · `education` · `women` · `media` · `health` | مجالات العمل السبعة |
| `pillar.html?id=summary` | معرّف قديم، يظل يعمل ويقود إلى أحدث تقرير |
| أي معرّف آخر | صفحة «غير موجودة» واضحة مع روابط المجالات |

## وسم الإصدار — مهم عند كل تحديث

ملفات `assets` مربوطة بوسم إصدار في الصفحتين:

```html
<script src="assets/js/data.js?v=2026-11-16"></script>
```

**ارفع هذا التاريخ في `index.html` و `pillar.html` بعد أي تعديل على `data.js` أو
`style.css` أو `app.js` أو ملفات اللغات.** بدونه يستمر متصفح الزائر في خدمة نسخة
قديمة من ذاكرته ولا يرى التحديث — وهذا ما حدث فعلاً أثناء التطوير.

## الصور الميدانية

```
assets/img/photos/field-01.jpg … field-10.jpg
```

عشر صور **معتمدة للنشر من التجمع**، أبيض وأسود بعرض 1600 بكسل (259 ميغابايت → 2.2).
مسجَّلة في `fieldPhotos` داخل `data.js`، وتُعرض شريطاً أفقياً في «من الميدان».

**بلا تعليق لكل صورة** — لا يُخترع وصف، ولا يُذكر موقع ولا حي. التسمية على مستوى
القسم فقط. لإضافة صورة: ضعها في المجلد وأضف سطراً في `fieldPhotos`.

**ما فُحص قبل النشر:** أسماء المستفيدين على الإفادات غير مقروءة عند مقاس الويب،
ولا شعار لجهة خارج التجمع في أي صورة. الصور المرفوضة تبقى في `_photos-staging/`
ولم تُنقل إلى الموقع.

## اللغات الثلاث

الموقع يعمل بالعربية والإنجليزية والتركية. **`data.js` عربي خالص ولا يُمس**؛ الترجمات
ملفات مستقلة تُدمج وقت التشغيل:

```
assets/js/i18n/en.js     الإنجليزية
assets/js/i18n/tr.js     التركية
```

- التبديل بـ `?lang=en` أو `?lang=tr`، ويُحفظ الاختيار في `localStorage`.
- `<html lang>` و `dir` يتبدّلان تلقائياً (العربية RTL، الأخريان LTR). التنسيق كله
  بخصائص منطقية (`inset-inline-*`) فالانقلاب يعمل بلا قواعد إضافية.
- **مفتاح الترجمة هو النص العربي نفسه** في جدول `ui`، فلا تُخترع مفاتيح ولا تنكسر
  العربية إن نقصت ترجمة.
- **لا تختلط اللغات في صفحة واحدة.** ما لم يُترجم بعد (بنود التفصيل، الجداول،
  الأقسام الختامية) لا يُعرض بالعربية داخل صفحة أجنبية، بل يظهر مكانه رابط
  «التفاصيل الكاملة متاحة بالعربية».
- إن لم يُحمَّل ملف اللغة لأي سبب، يرجع الموقع للعربية كاملة بدل صفحة نصفها مترجم.
- كل صفحة غير عربية تحمل شريط **«ترجمة غير معتمدة — بانتظار المراجعة»**. يُزال بحذف
  حقل `unapproved` من ملف اللغة بعد اعتمادك.

**لإضافة لغة رابعة:** انسخ `en.js`، غيّر `window.I18N.en` إلى رمز اللغة، وأضف سطراً
في `LANGS` داخل `app.js` وسطر `<script>` في الصفحتين.

### ما تُرجم وما لم يُترجم بعد

| | الحالة |
|---|---|
| الواجهة كاملة (قوائم، أزرار، تسميات) | ✅ مُترجَمة |
| الهوية الدائمة (رؤية، رسالة، قيم، أهداف، تطلعات، نشأة) | ✅ مُترجَمة |
| أسماء المؤسسات السبع | ✅ مُترجَمة |
| المجالات السبعة (عنوان، تخصص، جهات، تعريف) | ✅ مُترجَمة |
| عناوين التقارير وتسميات المؤشرات | ✅ مُترجَمة |
| افتتاحية كل مجال في كل تقرير | ✅ مُترجَمة |
| بطاقات الأرقام (مع وحداتها) | ✅ مُترجَمة |
| بنود التفصيل · الجداول · الأقسام الختامية | ⏳ بالعربية، مع رابط ظاهر |

**الأرقام لا تُترجم أبداً** — تُنقل كما نُشرت حرفاً بحرف في اللغات الثلاث.

## بنية الأرشيف

المحتوى المؤرَّخ كله في `reports.items[]`، مرتّبة من الأحدث إلى الأقدم، و`reports.current`
يطابق معرّف أحدها. **كل تقرير مكتفٍ بذاته**: فترته، ومؤشراته، وأقسامه لكل مجال.

```js
reports: {
  current: "q3-2026",
  items: [
    { id, label, range, reportTitle, reportFile,
      intro, metricsTitle, metrics, highlights, notice,
      sections: { dawah: {lead, groups, blocks, table, gallery}, quran: {...} },
      summary, appeal, reading, dataNotes, opportunities, closing }
  ]
}
```

`pillars[]` صارت **دائمة بحتة**: `id` و `num` و `title` و `short` و `orgs` و `definition` و `cover`.
لا محتوى فترة فيها إطلاقاً. وصفحة المجال تعرض تعريفه الدائم، ثم تبحث عن **أحدث تقرير يذكره**
وتعرض حصيلته موسومة بختم تلك الفترة — فالمجال الذي لم يَرِد في آخر تقرير لا تنكسر صفحته.

**لإضافة تقرير جديد:** أضف عنصراً في أول `reports.items` واجعل `current` معرّفه. لا شيء آخر.

لا صفحة مستقلة للمؤسسات الشريكة: بياناتها المعتمدة حالياً اسم وشعار فقط، وقسم الرئيسية
يستوعبها كاملة. حين تُعتمد النبذ التعريفية يصير إفرادها بصفحة قراراً مبرَّراً.

## 1 · خريطة المحتوى: ما الدائم وما المرتبط بفترة

القاعدة الحاكمة في الموقع: **كل نص أو رقم مرتبط بفترة يحمل وسم فترته بصرياً.**

| المحتوى | التصنيف | أين يسكن |
|---|---|---|
| `org` · `partners` · `mediaOffice` | دائم | الترويسة، قسم الشركاء، التذييل |
| `identity` · `founding` · `governance` | دائم (ناقص) | قسم «من نحن» — خانات محجوزة |
| `intro[0]` «يجسد التجمع صرحاً…» | **دائم** — مضارع تعريفي عن التجمع | «من نحن» بالرئيسية |
| `intro[1]` «يقدم **هذا التقرير** … الربع الثاني…» | **فترة** — مؤرَّخ بنصه | صفحة التقرير وحدها |
| `pillars[].title/short/orgs/num` | دائم | بنية المجالات |
| `pillars[].lead` لـ `dawah` و `quran` | **دائم** — مضارع تعريفي بالمجال | التعريف الدائم بالمجال |
| `pillars[].lead` لـ `relief` و `education` | **فترة** — ماضٍ وينتهي بنقطتين تمهيداً لأرقام الفترة | داخل كتلة «إنجازات الفترة» |
| `pillars[].lead` لـ `women` و `media` | `null` | خانة محجوزة |
| `groups` · `blocks` · `table` · `gallery` | فترة | كتلة «إنجازات الفترة» الموسومة |
| `metrics` · `summary` · `period` | فترة | «لمحة أثر» (٣ مؤشرات) + صفحة التقرير |
| `donors` «نسعى خلال **الربع القادم**…» | **فترة** | صفحة التقرير، لا الرئيسية |
| `contact` | ناقص | حاشية «الدعم والتواصل» + التذييل |

هذا التصنيف مخزَّن في حقول تقنية (`introScope` و `leadScope`) لا في الكود، فتغييره
سطر واحد في `data.js` إن رأى التجمع غير ذلك.

### أقسام الصفحة الرئيسية

`الافتتاحية` ← `صورة` ← `01 من نحن` ← `02 المؤسسات الشريكة` ← `03 مجالات العمل`
← `04 لمحة أثر` (مؤرَّخ) ← `05 التقارير` ← `06 الدعم والتواصل` ← التذييل.

الافتتاحية بلا تاريخ ولا رقم فترة: اسم التجمع، وخط، وشعاره، وحقائق دائمة في الحاشية.
**تبقى صحيحة بعد سنتين.** القسمان الوحيدان اللذان يتغيران بتغيّر التقرير هما
«لمحة أثر» و«التقارير»، وكلاهما يقرأ من `data.js` تلقائياً.

## 2 · الحقول الناقصة — تنتظر اعتماد صاحب المشروع

كلها `null` في `data.js`، وتظهر في الواجهة كخانة محجوزة معلَّمة (`.slot`).
**لم يُكتب لها نص ولم تُستنتج من التقرير.** بمجرد وضع القيمة تُستبدل الخانة تلقائياً
بالنص، بلا لمس CSS أو HTML.

| الحقل في `data.js` | ما يُنتظر | موضع الظهور |
|---|---|---|
| ~~`identity.vision`~~ | ✅ مُعتمد — من «الرؤية والرسالة.docx» | من نحن |
| ~~`identity.mission`~~ | ✅ مُعتمد — من «الرؤية والرسالة.docx» | من نحن |
| ~~`identity.values`~~ | ✅ مُعتمد — أربع قيم | من نحن |
| ~~`founding.year`~~ | ✅ 2026 | حاشية «من نحن» |
| ~~`founding.story`~~ | ✅ التعريف العام، فقرتان | من نحن |
| ~~`goals` · `aspirations`~~ | ✅ 10 أهداف + 3 تطلعات (حقلان جديدان) | من نحن |
| `governance` | طريقة الحوكمة واتخاذ القرار | من نحن |
| `partners[].logo` لـ `hamad` | **ملف شعار مركز الحمد الطبي** — البطاقة تعرض «شعار قيد الاستلام» | قسم الشركاء |
| `partners[].role` | تخصص كل مؤسسة | بطاقة المؤسسة |
| `partners[].about` | نبذة تعريفية عن كل مؤسسة | بطاقة المؤسسة |
| `pillars[].definition` | تعريف دائم بالمجال | رأس صفحة المجال |
| `reports.past` | التقارير السابقة | قسم التقارير |
| `period.reportFile` | ملف PDF للتقرير الحالي | التقارير + صفحة التقرير |
| `donors.donateUrl` | رابط الدعم | الدعم والتواصل |
| `donors.donateQr` | صورة كود QR | الدعم والتواصل |
| `contact.email/phone/address` | بيانات التواصل | الحاشية + التذييل |
| `contact.social.*` | روابط التواصل الاجتماعي | التذييل |

مثال تعبئة:

```js
identity: { vision: "…", mission: "…", values: "…" },
founding: { year: "2024", story: "…" },
reports: {
  current: "q2-2026",
  past: [
    { id: "q1-2026", label: "الربع الأول 2026", range: "…", title: "…", file: "reports/q1-2026.pdf" }
  ]
}
```

`partners[].role` و `about`: أيّهما مُلئ ظهر في البطاقة، ويختفي تنويه «نبذة كل مؤسسة»
من الحاشية تلقائياً حين تُملأ لمؤسسة واحدة على الأقل.

## 3 · قرارات التصميم

### العنصر التوقيعي: «المتن والحاشية»

كل صفحة تجري على مسارين يفصلهما **خط شعري واحد متصل** من أعلى الصفحة إلى أسفلها:

```
+------------------------------------------+ | +-----------------+
|  المتن — المؤسسة الدائمة                  | | |  الحاشية         |
|  نص كبير، سخيّ، ولا يظهر فيه تاريخ         | | |  01 · من نحن     |
|                                          | | |  سنة التأسيس     |
|  ...                                     | | |  [ غير معتمدة ]  |
|                                          | | |                  |
|  لمحة أثر: $ 1,972,687                    | | | |الربع الثاني 2026|  <- الختم
+------------------------------------------+ | +-----------------+
                                       الخط المتصل      الأحمر خط شعري لا مساحة
```

- **المتن** (`.sheet__main`) = المؤسسة الدائمة.
- **الحاشية** (`.sheet__aside`) = ترقيم القسم، والحقول الناقصة، وختم الفترة.
- **القاعدة:** أي قسم يحمل ختماً في حاشيته فمحتواه كله مرتبط بتلك الفترة، ومن لا ختم له فمحتواه دائم.
  في الصفحة الرئيسية **ختم واحد فقط**: قسم «لمحة أثر».

**لماذا هذا:** القاعدة الحاكمة في المشروع صارت **معمار الصفحة نفسه** لا شارة ملصقة على
عنصر. ومصدر الشكل تقليد المخطوط العربي — متن دائم وحاشية مؤرَّخة — فالطابع الإسلامي
حاضر **بنيوياً لا وعظياً**، في الترتيب لا في العبارات.

عند ≤999px يُطوى المساران: الحاشية تصير كتلة تعليق تحت متنها، يفصلها خط أفقي. الفكرة تنجو.

### المخاطرة المأخوذة

**التضحية بنحو 20% من عرض الصفحة لعمود يبقى صامتاً في معظم الأقسام.** الحاشية فارغة
عمداً حيث لا يوجد شيء مؤرَّخ، لأن الفراغ هناك **معلومة**: «لا شيء في هذا القسم مؤقت».
هذا ثمن حقيقي في المساحة، ومبرَّره أن الفصل بين الدائم والمؤقت هو أهم ما يحتاجه هذا الموقع.

### الإيقاع

فاتح ← فاتح ← فاتح ← **حبري داكن** (مؤشرات التقرير) ← فاتح ← **حبري** (التذييل).
الأرضية الداكنة الوحيدة داخل المحتوى في صفحة التقرير، فالرئيسية تبقى هادئة كما يليق
بموقع تعريفي دائم، والكثافة الرقمية تحدث حيث ينتظرها الزائر.

### الطباعة

`Zain` بمدى كامل من **200** إلى **900**. عنوان الافتتاحية بوزن **900** في
`clamp(2.15rem → 4.3rem)` و«متحدون» بالأخضر، ويقابله الشعار النصي بوزن **300**
و«ثبات» بالأحمر — التباين بين الثقيل والخفيف هو مصدر الحضور. أرقام ترقيم الأقسام
في الحاشية بوزن 200 في حجم كبير. المتن 400، عناوين الأقسام 800، عناوين الصفحات 900.

### الدفء البصري

الفخامة هنا ليست تجريداً من اللون. العناصر التالية مقصودة ومحفوظة:

- **الشعار كبيراً وبألوانه** في الافتتاحية — شجرة الزيتون داخل معيّن ألوان العلم هي
  أجمل ما في الهوية، ومكانها الافتتاحية لا الترويسة وحدها.
- **توهّج الأطراف** الأخضر/الأحمر و**شبكة الورق** مثبّتان خلف الصفحة (`body::before`
  و `body::after`) فلا تبدو الصفحة مسطّحة. الأشرطة الداكنة معتمة فتغطيهما.
- **شارات التعليق الملوّنة** على ركن كل لوحة صورة: خضراء في الرئيسية، زيتونية في
  الصفحات الداخلية.
- **الجذر الزيتوني** في قائمة مجالات العمل: ساق واحدة تستدقّ، وعقدة رقم، وفرع أفقي
  نحو كل عنوان. مأخوذ من جذور الزيتونة في الشعار، ومسوّغ استدقاقه أن نص `data.js`
  نفسه يصف المجال الأول بأنه «الأولوية القصوى والعمود الفقري لعمل التجمع».
- **المؤشرات ككروت** على ورق فاتح بحدّ شعري وانحناء موحّد.
- **الانحناء 14px** في الموقع كله — أدفأ من الحواف الحادة، وأبعد عن «تخطيط الصحيفة».
- **الترويسة لوح عائم** `position: fixed` لا شريط لاصق: `.site-header` غلاف شفّاف
  بـ `pointer-events: none` فلا يحجب النقر، و`.site-header__in` هو اللوح نفسه
  بانحناء `var(--r)` وسماكة `var(--line)` — العوم لا يبرّر شكلاً خاصاً، فلا كبسولة
  999px. يتكثّف عند التمرير (`html.is-scrolled`): 68px ← 56px ويُطوى اسم التجمع
  الكامل تحت الاختصار. الكبسولات محجوزة لمبدّل اللغة وحده، والصفحة الحالية في
  القائمة تُعلَّم بخط شعري زيتوني لا بخلفية.
  ثلاث قيم مرتبطة به لا تُعدَّل منفردة: `#main > *:first-child:not(.hero)` يفتح
  مكان اللوح في الصفحات الداخلية (اللوح خارج التدفّق)، و`.band[id]`
  `scroll-margin-top`، و`.hero` `min-height`.
- **تنويه الترجمة غير المعتمدة** (`.xbanner`) مثبّت فوق اللوح. `app.js` يقيس
  ارتفاعه في `--xb`، ويضيف `has-xbanner` على `<html>`، فينزل اللوح وينزاح `body`
  وتُطرح القيمة من ارتفاع الافتتاحية. يُقاس من جديد عند تغيّر عرض النافذة.
- **الافتتاحية سلايدر** (`heroSlider()` في `app.js`): الشريحة الأولى هي صورة
  التجمع ونصّها الثابت (عدد المؤسسات والمجالات)، ثم **شريحة لكل مجال عمل له
  غلاف** — صورته ونصّه هو: رقم المجال وعنوانه وتعليق الصورة، كلها من
  `data.js` حرفياً. لا نصّ مخترع.
  العدد مشتقّ من `pillars` بـ`filter` على وجود الغلاف، فلا يفترض التخطيط
  عدداً. **مجال «الرعاية الصحية» (07) غلافه `null` فلا شريحة له**؛ ما إن
  يُضاف غلافه في `data.js` حتى يدخل السلايدر وحده.
  - **الانتقال كشفٌ لا حركة:** `clip-path: inset()` تنزاح عن الصورة الجديدة
    من جهة بدء السطر (تنعكس تلقائياً مع `html.is-ltr`). الصورة نفسها لا
    تتحرّك ولا تتكبّر — فلا حركة تُفرض على مادّة جادّة، والشكل هندسي كبقية
    مفردات الموقع، لا تلاشٍ عام ولا Ken Burns.
  - الطبقات السابقة **تبقى مكشوفة تحت الجديدة**، والترتيب بـ`z-index` يضبطه
    `app.js` لا بترتيب العناصر — فالرجوع إلى شريحة سابقة يعمل كالتقدّم سواء،
    ولا تظهر فجوة أثناء الكشف.
  - ألواح النص متراكبة في **خلية شبكة واحدة**، فارتفاع الحيّز هو ارتفاع
    أطولها ولا يقفز التخطيط عند التبديل. النص يتلو الصورة بتأخير 0.4s ثم
    سطراً سطراً.
  - الدوران كل 7s، ويتوقّف **نهائياً عند أول تدخّل** من المستخدم — هي آلية
    الإيقاف التي يوجبها معيار الوصول لكل محتوى يتحرّك تلقائياً — ويتوقّف
    مؤقتاً أثناء القراءة على البطاقة وفي اللسان الخلفي، ويُلغى كلياً مع
    `prefers-reduced-motion` (تبقى المؤشّرات تعمل بلا انتقال).
  - الصور ما عدا الأولى `data-src`، تُحمَّل عند الحاجة مع تحميل مسبق
    للتالية، فلا تُثقل أول رسم للصفحة.
  - **`relief-parcel.jpg` مقاسها 1400×479** (شريط بانورامي) فتُكبَّر 1.88×
    في افتتاحية بملء النافذة. تعمل، لكنها أقلّ حدّة من بقية الأغلفة.
- **الافتتاحية بلا سقف ارتفاع**: أي سقف أقلّ من ارتفاع النافذة يُطلّ القسم
  التالي من تحتها. `min-height: max(560px, calc(100svh - var(--xb, 0px)))`.
- **تنعيم التمرير** (`smoothWheel()` في `app.js`): تخميد أُسّي على **عجلة الفأرة
  وحدها**. اللمس له قصوره الذاتي الأصلي وخطفه يفسده، ولوحة المفاتيح وروابط
  المراسي تبقى على `scroll-behavior: smooth` في الـCSS. يُلغى كلياً مع
  `prefers-reduced-motion` ومع المؤشّر الخشن (`pointer: coarse`).
  مقبضا الضبط في أول الدالة: `TAU` (150ms — أكبر = أبطأ وأنعم) و`MULT`
  (مضاعف مسافة النقرة، يُترك 1 لئلا تثقل الصفحة).
  أربعة قرارات فيها ليست اعتباطاً:
  1. **التمرير أصلي** — `scrollTo` لا تحريك للـ`body` بـ`transform`، وإلا
     انكسرت الترويسة `position: fixed`.
  2. **`behavior:"instant"`** لكل إطار، فلا تُقلَب خاصية CSS ولا يبقى شيء
     عالقاً إن غابت إطارات الرسم. إن لم يدعمه المتصفح لم يعمل التنعيم أصلاً.
  3. **حدّ `dt` عند 200ms لا 50**: مع سقوط الإطارات يلحق التخميد نفسه بالزمن
     الحقيقي. بـ50 كانت الحركة تتقدّم بالإطار لا بالزمن فتقف دون هدفها —
     قيس ذلك فعلاً عند 6 إطارات/ثانية فوقفت عند 375 من 400.
  4. **المناطق ذات التمرير الرأسي الخاص** لا تُخطف منها العجلة. شريط الصور
     أفقي (`scrollHeight == clientHeight`) فالعجلة فوقه تمرّر الصفحة.
- **كسر القائمة عند 1200px** لا 1100: أطول قائمة (التركية) تحتاج ~1174px.
  الكسر موحّد للغات الثلاث لأن نصوص الترجمة لم تُعتمد بعد وقد تطول.

### حراسات مطبَّقة

- **لا محدِّد على شكل `.section a`.** كل رابط عنصري مخصَّص تحت صنف ابن
  (`.pnav__card` · `.field__link` · `.nav__a` · `.footer__list a`) حتى لا يتكرر ما
  أصاب `.btn` سابقاً حين غلبته قاعدة `.pillar-nav a` فامتد بعرض الصفحة.
- **سماكة حد واحدة** (`--line: 1px`) وانحناء واحد (`--r: 6px`) في الموقع كله.
- **لا لون خارج الهوية.** الأسود والأبيض الخامان لا يردان إلا داخل `@media print`.
- **الأرقام:** `--len` يضبط مقاس الخط تبعاً لطول النص المعروض — ضبط طباعي بحت لمنع
  الطفح. لا يُشتق منه رقم ولا يُعاد تنسيق قيمة. والمؤشر الموسوم `accent: true` في
  `data.js` يتصدّر بصفّ كامل: الهرمية من وسم في المصدر لا من حكم على قيمة الرقم.
- **الأرقام في سياق RTL** معزولة بـ `unicode-bidi: isolate` و `<bdi>` فتحاذي حافة
  القراءة (اليمين) وتُقرأ داخلياً يساراً-يميناً.

### ما حُذف

1. **خانة «التخصص» المكررة في كل بطاقة شريك** — ستّ خانات متطابقة «بانتظار الاعتماد»
   كانت ضجيجاً. التنويه صار مرة واحدة في حاشية القسم، والبطاقة نظيفة، والنص يظهر
   داخلها تلقائياً حين يُعتمد.
2. **الرقم المكرر في صفحة المجال** — كان يظهر مرتين، في المتن وفي الحاشية.

### مراجعة بعد أول عرض

النسخة الأولى من إعادة التصميم بالغت في التجريد: حذفت الشعار الكبير ودفء الخلفية
والعنوان العريض وشارات الصور والجذر الزيتوني، فخرجت الصفحة منضبطة لكن باردة وأقرب
إلى غير المكتملة منها إلى الفخمة. أُعيدت هذه العناصر كلها، وبقيت البنية (المتن
والحاشية، وفصل الدائم عن المؤرَّخ) كما هي — فالتموضع والقشرة أمران منفصلان.

**النسخة السابقة للموقع محفوظة كاملة في مجلد `_v1/`** ويمكن تشغيلها ومقارنتها في أي
وقت (`python -m http.server 8124 --directory _v1`). لم تُحذف.

## 4 · التحديث الدوري

عدّل `assets/js/data.js` فقط. لا حاجة لفتح CSS أو HTML.

1. **الفترة**: حقل `period` — المعرّف والتسمية والمدى وعنوان التقرير وملف PDF.
2. **التقرير السابق**: انقل الفترة المنتهية إلى `reports.past` قبل تحديث `period`.
3. **المؤشرات**: مصفوفة `metrics`. و`homeMetrics` يحدد كم مؤشراً يظهر في «لمحة أثر»
   بالصفحة الرئيسية، من أول المصفوفة وبترتيبها.
4. **المجالات**: مصفوفة `pillars`. كل مجال فيه `groups` أو `blocks` أو `table` أو مزيج.
5. **جدول الملخص**: كائن `summary`.

قواعد ملزِمة عند التحديث، وهي مطبّقة في النسخة الحالية:

- النصوص منقولة حرفياً من التقرير. لا اختصار ولا إعادة ترتيب ولا تصحيح صياغة.
- لا يُدخل رقم محسوب أو مشتق غير منصوص عليه في التقرير.
- الحقول غير المعتمدة تبقى `null`، والواجهة تعرضها كخانة محجوزة معلَّمة بدل أن تخترع بديلاً.

الأرقام داخل النصوص تُلوَّن بالأخضر تلقائياً وقت العرض. تلوين فقط — لا يغيّر النص
ولا يعيد تنسيق الرقم.

## إضافة مؤسسة شريكة

سطر واحد في مصفوفة `partners`:

```js
{ id: "hamad", name: "مركز الحمد الطبي", logo: "assets/img/logos/hamad.png",
  site: null, role: null, about: null }
```

ثم ضع ملف الشعار PNG بخلفية شفافة وارتفاع 400 بكسل في `assets/img/logos/`.
**لا شيء في التصميم مرتبط بعدد المؤسسات**: قسم الشركاء والتذييل والعدّاد تقرأ من
المصفوفة نفسها، والشبكة `auto-fill` تتكيّف. اختُبرت بثمانية شركاء وثمانية مجالات:
ثلاثة صفوف منتظمة، وعرض بطاقة موحّد، وصفر تمدد أفقي في المقاسات الثلاثة.
القاعدة نفسها تنطبق على عدد المجالات وعدد التقارير.

## الخطوط

الموقع يستدعي **Zain** من Google Fonts.
**29LT Bukra** المعتمد في الهوية ترخيصه تجاري ويحتاج ترخيص ويب منفصل. Zain من المسبك
نفسه (29LT) فقرابة الشكل محفوظة، لكنه بديل لا مطابق.
عند شراء ترخيص Bukra للويب: ضع ملفات `woff2` في `assets/fonts/`، وأضف `@font-face`
أعلى `style.css`، وقدّم `"29LT Bukra"` على `"Zain"` في المتغير `--f`.

## الصور

كل الصور أبيض وأسود، وهو قرار هوية مأخوذ من تصاميم السوشيال لا فلتر CSS: التحويل تمّ
في الملفات نفسها فهي أخفّ. شعارات المؤسسات وحدها تبقى بألوانها على كرت فاتح.

قواعد مطبّقة: لا أسماء مواقع أو أحياء في أي تعليق صورة، ولا محتوى طبي أو سريري، ولا
شعارات جهات خارج التجمع. صورة `water-line.jpg` قُصّ جانبها الأيسر بالكامل لإزالة شعار
جهة خارجية ظاهر على الخيمة. ولا تجسيد لذوات الأرواح في أي رسم أو أيقونة أو خلفية:
الأشكال المستعملة هندسية وخطية فقط (معيّن، خط، دائرة).

## النشر

ملفات ثابتة، فأي استضافة ثابتة تكفي: Netlify أو Cloudflare Pages أو GitHub Pages أو
استضافة عادية. ارفع محتويات المجلد كما هو. لا خطوة بناء ولا تبعيات ولا `npm install`.

```bash
python3 -m http.server 8000
```

**لماذا لا Supabase**: المحتوى يتغيّر أربع مرات في السنة، ولا مستخدمين ولا حسابات ولا
بيانات تُكتب من الزائر. Supabase هنا طبقة تعقيد بلا مقابل، وهي ليست استضافة واجهة أصلاً
فستحتاج Netlify معها بأي حال. فصل المحتوى في `data.js` يعطي الفائدة نفسها.

## 5 · مسائل معلّقة تحتاج قراراً

1. **عدد المؤسسات**: غلاف التقرير يذكر ستاً. شريط الشعارات في تصاميم السوشيال يعرض
   سبعاً بإضافة مركز الحمد الطبي. جدول الملخص يذكر «القطاع الصحي والأدوية» كبند مستقل
   بلا مجال يقابله. الموقع يعتمد الستة حالياً، والسطر السابع جاهز معلَّقاً في `partners`.
2. **الحقول الناقصة** المذكورة في §2 — كلها تنتظر اعتماد التجمع.
3. **«الاستفادة الاغاثية»** وردت في التقرير بلا همزة قطع، ونُقلت كما هي ولم تُصحَّح.
4. **تعارض رقمي داخل التقرير**: جدول الملخص يذكر 3,411 طالباً للتعليم المدرسي، والمجال
   الرابع يذكر 3,360. كلا الرقمين منقول كما ورد في موضعه دون توحيد.
5. **تصنيف نصوص `lead`**: صُنِّف `dawah` و `quran` تعريفاً دائماً (مضارع تعريفي)،
   و`relief` و `education` تمهيداً لحصيلة الفترة (ماضٍ ينتهي بنقطتين). إن رأى التجمع
   غير ذلك فالتغيير قيمة `leadScope` في `data.js` لا أكثر.
6. **عنوان «من نحن»** وسائر تسميات الواجهة (تفاصيل المجال، كل المجالات، إنجازات الفترة،
   لمحة أثر، التقارير، الدعم والتواصل) تسميات واجهة أُضيفت للتنقل، وليست نصوصاً تعريفية
   عن التجمع.

## 6 · تدقيق منفَّذ قبل التسليم

- **قيم `data.js` لم تتغير حرفاً**: قورنت كل السلاسل النصية وكل الأعداد بين النسخة
  الأصلية والحالية — 287 سلسلة نصية موجودة كلها بعددها نفسه. المضاف حقول تقنية فقط:
  `"q2-2026"` و `"permanent"` و `"period"` و العدد `3` (قيمة `homeMetrics`). صفر حذف
  وصفر تعديل. المجاميع 402,502 و 1,136 و 12,013,597 مثبّتة كما وردت.
- الصفحات كلها تُبنى **بلا أخطاء console**، والمعرّف الخاطئ يعطي صفحة واضحة.
- **صفر تمدد أفقي** عند 390 و 768 و 1360 بكسل: `scrollWidth == clientWidth` في
  الرئيسية وصفحة التقرير وصفحات المجالات. الجدول العريض يمرّر داخل حاويته وحدها.
- **تباين النص يجتاز WCAG AA**: فحص آلي لكل عنصر نصي في كل صفحة مقابل أرضيته الفعلية،
  بعتبة 4.5:1 للنص العادي و 3:1 للكبير — **صفر إخفاق**. حُذفت الطبقتان
  `rgba(26,26,26,.45)` (2.85:1) و `rgba(26,26,26,.60)` (4.49:1) من النسخة السابقة
  لسقوطهما، واستُبدلتا بـ `.72` (6.74:1) و `.65` (5.30:1).
  ومُنع `--red-soft` على الزيتوني (2.60:1) و `--green-soft` على الزيتوني (3.91:1)،
  فصار الشريط الكثيف حبرياً لا زيتونياً.
- **التنقل بلوحة المفاتيح** يعمل، ومؤشر التركيز ظاهر: إطار أحمر 2px بإزاحة 4px على
  الفاتح، وأحمر فاتح على الداكن، متحقق بضغط Tab فعلي ومطابقة `:focus-visible`.
- **قائمة الجوال** تحدّث `aria-expanded` (false ⇄ true)، وتُغلق بـ Escape وبالنقر على رابط.
- **`prefers-reduced-motion` محترم فعلاً**: يوقف كل `transition` و `animation` بـ
  `!important` على كل العناصر، ويُلغي `scroll-behavior: smooth`، ويُظهر كل عناصر
  الكشف التدريجي فوراً.
- **الافتتاحية ورؤوس الصفحات الداخلية لا تظهر تدريجياً** (`noReveal`): أول ما يراه
  الزائر مرسوم فوراً، فلا يستقبله بياض.
- **اختبار التوسع**: بثمانية شركاء وثمانية مجالات — لا كسر ولا تمدد في المقاسات الثلاثة.
